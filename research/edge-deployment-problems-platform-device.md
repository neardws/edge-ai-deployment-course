# 边缘部署问题候选库：设备与平台约束

> 收集日期：2026-07-10。本文是供课程后续筛选、改写和实测的候选资料池，不是课程结论，也不代表所有版本、芯片或设备都存在同一问题。

## 收集口径

- 只把官方文档、项目维护方文档或官方仓库作为核心证据。
- “已有”表示课程已经直接覆盖该现象和主要处理方向；“扩展”表示课程只讲了原则，尚缺具体诊断或平台边界；“新增”表示当前排障索引和相关章节尚未发现对应条目。
- 解决方案都要在目标设备上复测。设备专属限制不外推到其他平台，版本相关建议上线前重新核对。

## 建议优先吸收的 5 条

1. **DEV-04 JetPack 局部升级导致软件栈失配**：能把课程现有的版本记录要求补成明确的升级风险和可回滚检查。
2. **DEV-10 NNAPI 废弃与迁移**：属于会随 Android 平台演进而失效的关键路线判断，应在移动端扩展页明确标注。
3. **DEV-11 ORT Mobile 分区与动态 shape**：把“算子覆盖率高”与“真实端到端加速”区分开，适合作为 runtime 选型案例。
4. **DEV-13 LiteRT Micro tensor arena**：补上微控制器部署中最典型、又不能用模型文件大小解释的内存故障。
5. **DEV-17 Core ML 跨 compute-unit 数值差异**：把精度回归、硬件分区和性能取舍连接起来，适合进入精度恢复章节。
